# Datos de prueba del cliente PYME

En este cliente Ubuntu, la carpeta usada como origen de las copias de seguridad es:

/datos_pyme

Esta carpeta representa los datos de una pequeña empresa que SecureTECH protege mediante copias de seguridad con Restic.

El script backup.sh utiliza esta ruta como origen del backup, según la variable BACKUP_PATH definida en /etc/securetech/client.env.
